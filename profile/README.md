<h1 align="center">Minimal</h1>

<p align="center"><strong>Run your agent in a Minimal box. Ship and run software with isolation on your own computer.</strong></p>

<p align="center"><a href="https://minimal.dev">minimal.dev</a></p>

- [minimal](https://github.com/gominimal/minimal): the `min` CLI, daemon and microVM host
- [pkgs](https://github.com/gominimal/pkgs): the curated package registry every box is built from
- [minimal-skills](https://github.com/gominimal/minimal-skills): the Claude Code plugin that sets Minimal up for you
- [Documentation](https://minimal.dev/docs)

If you are a coding agent setting up Minimal for your user, install the plugin and follow its `minimal-setup` skill:

```shell
claude plugin marketplace add gominimal/minimal-skills
claude plugin install minimal@gominimal
```
